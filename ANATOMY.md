# Repository Anatomy

_Stub — will be regenerated by `/anatomy` once Phase 8 lands._

## Tree (post-rewrite)

```
apps/
├── web/              # Next.js 15 + Tailwind 4 + Web Audio
│   ├── app/          # App Router pages (auth + studio)
│   ├── components/   # studio/ + ui/ components
│   ├── lib/audio/    # Web Audio engine (PadNode, EffectsBus, recorder)
│   ├── hooks/        # useAudioEngine, usePad, useRecorder
│   ├── e2e/          # Playwright behavioural + visual specs
│   └── public/samples/
└── api/              # Fastify auth + loops + presigned URLs
    └── src/
        ├── routes/   # auth, loops, sessions, health
        ├── services/ # auth, loop, s3
        ├── db/       # users, loops, sessions (DynamoDB DocumentClient)
        └── middleware/

packages/
└── shared/           # zod schemas + types + constants

infra/
├── terraform/        # validate-only modules (s3-loops, dynamodb, iam, cloudfront)
└── docker/           # docker-compose + seed.sh for DynamoDB Local + LocalStack

.claude/              # Claude Code config (settings, hooks, commands, rules)
docs/wiki/            # LLM-maintained per-area wiki — regenerated by /anatomy
```

See `CLAUDE.md` for the full conventions, and per-package `CLAUDE.md` files
for area-specific rules. The previous blog/social API state is preserved at
the `pre-rewrite-snapshot` git tag.
