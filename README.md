# Claude Code Demo — Music Looper

A working music looping web app, used as a vehicle for **demoing and onboarding to Claude Code**. The app is the substrate; the focus is the `.claude/` configuration around it.

```sh
pnpm install
cp .env.example .env       # set JWT_SECRET, or set DDB_USE_STUB=1 + S3_USE_STUB=1
pnpm dev                   # web on :3000, api on :3001
```

## What you're looking at

| Path | What it is |

| [`.claude/`](.claude/) | Claude Code config — settings, hooks, rules, commands, agents, skills, plans. **The point of this repo.** |
| [`.claude/README.md`](.claude/README.md) | Map of the config. Read this second. |
| [`apps/`](apps/) | The app Claude rewrote. Next.js studio + Fastify api. |
