# Bundled sample credits

The studio ships **no recorded audio files** — its bundled samples are
synthesised in-process at page load (`apps/web/lib/audio/synth.ts`). That
means there is nothing to license in this repo today, and `apps/web/public/samples/`
contains only a `.gitkeep` placeholder.

## When to fill this in

If you later decide to bundle real audio (e.g. CC0 drum loops from
Freesound), record each file here in the table below.

## Format

| File | Source URL | Author | License |
|------|-----------|--------|---------|
| _none yet_ | | | |

## Sources to prefer

- **Freesound** — filter on license = "CC0". Best-curated CC0 catalogue.
- **Mixkit Free Music** — only the explicitly-CC0 tracks; the "Mixkit License"
  is *not* CC0 and has redistribution constraints.

## Sources to avoid

- **Splice "Free Sample Pack"** — TOS forbids redistribution. Don't bundle.
